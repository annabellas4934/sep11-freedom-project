# Entry 1
##### 11/09/26

## Context: 
I was inspired by a deck of cards on the desk. In class me and Franco would spread the cards and pick a card out and look at it, hoping we would get a high value card. This inspired me to make a wishing simulator game based off of cards. This [Honkai Star rail wishing simulator](https://hsr.wishsimulator.app/) is what I'm trying to do on a lower scale. You could pull as much as you like and you can check your inventory. I wanted a smooth pulling animation and stumbled upon [Animejs](https://animejs.com) which has super smooth animations. The HSR wishing sim has the feature to check what you already claimed, and to do this you need a database. My partner Evangelina Ermakova is working on [Firebase](https://firebase.google.com/), a tool for storing data. 

## Skills:
* **Collaboration**: When I found out that in order to store data I needed to use something like firebase, something difficult to learn and blocked from the school, I was thinking about not doing Firebase at all and just using Animejs and trying out Firebase later if I had time, but then Evangelina came to me asking to work on the project with me since she was interested in my project idea. I told her how I wanted to store data with Firebase, and she took up the job. Having her work on Firebase will definitely help make the game much more fun and it would be great to also have her work on the creative side of the project as well. Rather than drawing everything myself, she offered to help me with the art too. This help took much of the work off my hands.

* **Learning on my own**: To install Animejs type "npm install animejs" into the terminal. This was difficult to find out because when I was looking at Animejs tutorials, they all started with animejs already installed, and the [official website section for installing](https://animejs.com/documentation/getting-started) only had the text "npm install animejs", and I did not know what "npm" meant. Last year to install tools all I had to do was link the tool in the HTML file. After installing it, I thought I could navigate using the content on my own, but I was lost. I tried to paste code straight from the site to my files and nothing appeared. In desperation I used Ai to tell me what was wrong. I used Ai's code but only a square appeared and no animation was connected to it. I went back to it, watched a video, realized some things on what to do, and tried out something smaller. The videos themselves are old and outdated so they didn't work. I just messed around with what the site gave me, looked at my file to see if things were there, and finally I made some boxes move.

## EDP: 
I'm currently identifying the problem and doing some research about it in my Engineering design process, which would be that many games with a gacha system built in it, were programmed in a way where if you want something you would have to roll for it, and at a certain point you would be guaranteed it. By doing this, these big companies are able to make money as they would make it so that the player can buy what they want, spending money to reach that guaranteed point. Some players only play to pull on these gacha games. 

The next step for this project is to brainstorm some ideas that I could implement in my project that would help this issue. So far I have been thinking about making my game be totally random and require no money to roll.
